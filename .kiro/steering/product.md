# Product Overview

Material React Table (MRT) is a fully-featured React data table library built on top of Material UI V6 and TanStack Table V8. It provides a comprehensive solution for creating complex, interactive data tables with Material Design styling.

## Core Purpose

Quickly create feature-rich React data tables with minimal configuration while maintaining full customization capabilities.

## Key Features

- 40+ built-in features (all opt-in/opt-out)
- Sorting, filtering, pagination (client-side and server-side)
- Column ordering, resizing, pinning, hiding
- Row selection, expansion, grouping, virtualization
- CRUD operations with 5 editing modes
- Drag-and-drop for rows and columns
- Localization support (40+ languages)
- TypeScript-first with advanced generics
- SSR compatible
- Bundle size: 30-56kb gzipped

## Target Users

Developers building React applications who need sophisticated data tables with Material Design aesthetics and don't want to build table features from scratch.

## Related Projects

- Sister project: Mantine React Table (same API, different UI library)
- Built on: TanStack Table V8 (headless table logic)
- Styled with: Material UI V6 (component library)
